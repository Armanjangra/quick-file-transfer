# ⚡ Quick File Transfer

> A fast, cross-device local Wi-Fi file sharing desktop application built with Electron and Express.

![Quick File Transfer Banner](https://via.placeholder.com/800x400?text=Quick+File+Transfer+UI+Preview)

## ✨ Features
- 🚀 **Lightning Fast**: Transfer files over local Wi-Fi without internet usage.
- 📱 **Cross-Platform**: Share files seamlessly between Windows PCs, phones, and tablets.
- 🌙 **Dark Mode**: Persistent dark theme support.
- 📊 **Real-time Progress**: Live upload speed and percentage indicator.
- 🔒 **Local & Secure**: Files stay on your local network.

## 📥 Download Executable
Go to the [Releases](https://github.com/Armanjangra/quick-file-transfer/releases) section to download the latest `.exe` installer.

## 🛠️ Development Setup

```bash
# Clone the repository
git clone [https://github.com/Armanjangra/quick-file-transfer.git](https://github.com/Armanjangra/quick-file-transfer.git)

# Install dependencies
npm install

# Run in development mode
npm start

# Build Windows installer
npm run dist
